A imagem é lida pelo Claude, que lista todos os cursos, coordenadores e datas.
Para ler a imagem automaticamente, coloque sua chave da API da Anthropic em Configurações. Sem chave, use a aba “Colar dados”.

Cole uma lista de cursos (um por linha: Curso ; Coordenador ; dd/mm/aaaa) ou o JSON {"cursos":[{"nome","coordenador","data_inicio","data_fim"}]}.

Backup dos dados

Os dados ficam salvos neste navegador. Baixe um backup de vez em quando, ou para abrir em outro computador.

Configurações

A chave fica guardada só neste navegador e não entra no backup. Crie em console.anthropic.com → API Keys. Cada leitura de imagem custa alguns centavos.

Com o link, tudo é salvo automaticamente na Planilha Google e aparece igual em qualquer computador. Para os professores, mande o link do site com ?planilha= + este link no final.
